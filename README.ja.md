# Form Plant

WordPress用の多機能フォームプラグイン

## 概要

Form Plantは、モーダルベースの簡単なセットアップと柔軟なカスタマイズ機能を備えた多機能フォームプラグインです。

## 特徴

- **直感的なモーダルUI** - フィールド設定が簡単にできるモーダルインターフェース
- **HTMLレイアウト編集** - ショートタグを使った柔軟なレイアウト
- **豊富なフィールドタイプ** - テキスト、メール、電話番号、セレクトボックス、ファイルアップロードなど
- **確認画面** - 送信前に確認画面を表示
- **メール通知** - 管理者通知メールと自動返信メール
- **送信データ管理** - 管理画面から送信データの閲覧・エクスポート
- **REST API対応** - iframe/JavaScriptで外部サイトにフォームを埋め込み可能
- **スパム対策** - reCAPTCHA v3対応

## 動作要件

- WordPress 6.0以上
- PHP 8.0以上
- MySQL 5.7+ / MariaDB 10.3+

## インストール

1. `form-plant`フォルダを`wp-content/plugins/`ディレクトリにアップロード
2. WordPress管理画面の「プラグイン」メニューからForm Plantを有効化
3. 「Form Plant」メニューから新しいフォームを作成

## 基本的な使い方

1. **フォームを作成** -「Form Plant」→「新規追加」からフォームを作成
2. **フィールドを追加** -「フィールド設定」タブでフォームフィールドを追加
3. **レイアウトを編集** -「レイアウトエディタ」タブでHTMLテンプレートをカスタマイズ（任意）
4. **設定を構成** -「フォーム設定」タブでメール通知を設定
5. **埋め込み** - 固定ページや投稿にショートコード`[fplant id="FORM_ID"]`を挿入
