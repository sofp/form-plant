# Form Plant

確認画面・送信データ保存・外部サイト埋め込みを標準搭載した、すぐに使えるWordPressフォームプラグイン

## 概要

Form Plantは、確認画面、送信データの保存、CSVエクスポートを標準機能として搭載したWordPressフォームプラグインです。追加プラグインは不要です。

多くのフォームプラグインでは、確認画面やデータ管理に追加の拡張機能が必要です。Form Plantはこれらの基本機能を最初から備えているため、数分で本格的なお問い合わせフォームを構築できます。

## Form Plantの特長

- **確認画面を標準搭載** — 送信前にユーザーが入力内容を確認できます。追加プラグイン不要。
- **送信データの保存** — すべてのフォーム送信データがデータベースに保存され、管理画面から管理可能。
- **CSVエクスポート** — 送信データをいつでもダウンロード。レポートやバックアップに。
- **外部サイトへの埋め込み** — iframeまたはJavaScriptスニペットで、WordPress以外のサイトにもフォームを表示可能。
- **Webhook** — 送信内容を署名付きJSONでZapier / Make / 自作APIへ送信。配信結果の記録と自動リトライ付き。
- **MW WP Formからの移行** — 既存のMW WP Formのフォーム（フィールド・バリデーション・メール設定）を、内蔵の移行ツールで取り込み。一から作り直す必要はありません。
- **かんたんセットアップ** — ACFライクな直感的なアコーディオンエディターで、コードを書かずにフォームを作成。
- **デザインもノーコードで調整** — 色・サイズ・余白などを、ライブプレビューを見ながら管理画面から変更可能。
- **柔軟なカスタマイズ** — カスタムHTMLテンプレート、バリデーションメッセージ、送信後アクションで自由に制御。

## 機能一覧

- ACFライクなアコーディオンUIでフィールド設定、アイコン付きのフィールドタイプ選択
- ライブプレビュー付きのデザイン調整 — CSSを書かずに色・サイズ・余白をカスタマイズ
- フィールドごとの説明文を3箇所に表示（項目名の下 / 入力欄の上 / 入力欄の下、HTML可）
- 実際のテーマ内でのフォームプレビュー（PC / タブレット / モバイル切り替え対応）
- ブロックエディタ（Gutenberg）対応 — 専用「Form Plant」ブロックでフォームを埋め込み
- MW WP Form移行ツール — 既存フォーム・バリデーション・メール設定をForm Plantのフォームに変換
- URLパラメータ（`?post_id=`）で投稿のタイトルやカスタムフィールドをフィールド初期値に自動セット（MW WP FormのURL引数機能に相当）
- メール通知（管理者通知・自動返信）
- Webhook — 送信ごとに署名付きJSON（HMAC-SHA256）を外部URLへ配信、失敗時の自動リトライと配信結果の記録
- 同意（acceptance）フィールド — プライバシーポリシー等への同意用のリンク付きチェックボックス
- カスタムHTMLテンプレート対応（入力画面・確認画面、WordPressショートコードの展開に対応）
- 送信前の確認画面
- カスタムバリデーションメッセージ
- 送信後アクション（メッセージ / カスタムHTML / リダイレクト）
- 2タイプの日付入力（カレンダー / プルダウン）
- 郵便番号検索による住所自動入力（日本）
- 多層的なスパム対策: ハニーポット、時間ベースチェック、IPレート制限、使い捨てメールブロック、Google reCAPTCHA v2/v3、Cloudflare Turnstile
- iframe / JavaScriptでの外部サイト埋め込み
- 送信データの保存・管理
- 送信データのCSVエクスポート
- ファイルアップロード対応

## 動作要件

- WordPress 6.0以上
- PHP 8.0以上
- MySQL 5.7+ / MariaDB 10.3+

## インストール

1. `form-plant`フォルダを`wp-content/plugins/`ディレクトリにアップロード
2. WordPress管理画面の「プラグイン」メニューからForm Plantを有効化
3. 「Form Plant」メニューから新しいフォームを作成

## 基本的な使い方

1. **フォームを作成** -「Form Plant」→「新規追加」からフォームを作成
2. **フィールドを追加** -「フィールド設定」タブでフォームフィールドを追加
3. **レイアウトを編集** -「レイアウトエディタ」タブでHTMLテンプレートをカスタマイズ（任意）
4. **設定を構成** -「フォーム設定」タブでメール通知を設定
5. **埋め込み** - 固定ページや投稿にショートコード`[fplant id="FORM_ID"]`を挿入
